\section{项目经历}


\datedsubsection{\textbf{远端 PCIe 外设透明接入与事务追踪系统}\ \ \ \ \ \ \textit{方向：I/O虚拟化}}{2025.04 -- 至今}

\begin{itemize}[parsep=0.2ex]
\item 设计实现虚拟PCIe Switch：硬件模块vSwitch做枚举事务解析并传递到主机；主机程序借助QEMU维护虚拟配置空间，协调 FPGA 侧配置访问与 BAR 路由，使 Linux 可按标准流程枚举完整 PCIe Switch与外设拓扑。
\item 设计实现远端 NVMe 设备访问链路，实现 BAR/MMIO/doorbell 拦截、XDMA 消息转发、DMA 地址改写与虚拟中断注入，支持标准 NVMe 驱动进行队列初始化与数据传输。
\item 效果：支持用户按需定义 DUT 可见的 PCIe 拓扑与外设组合，并对配置访问、设备响应和 I/O 过程进行事务追踪与可控故障注入。
\item \textit{部分工作成果在 \textbf{FPGA领域顶刊-FCCM 2026}展示（第一作者）。}
\end{itemize}

\datedsubsection{\textbf{SoC-FPGA 可计算存储设备架构与统一编程模型}\ \ \ \ \ \ \textit{方向：近存储计算}} {2024.07 -- 2025.06}
\begin{itemize}[parsep=0.2ex]
  \item 将 SoC-FPGA 计算存储设备抽象为可编程外设：主机应用通过统一接口管理设备内存、加载程序并提交执行任务，使数据可在靠近存储的设备侧完成处理。
  \item 为承载设备内存读写、程序加载等不同请求，完善用户缓冲区到内核传输请求的映射与组装；支持控制命令携带程序片段、数据读写独立传输。
  \item 基于 SPDK 完善设备侧 DMA 队列的轮询与命令分发，异步处理设备内存读写、拷贝、内存范围管理和程序执行，并向主机回传完成状态。
\end{itemize}

\datedsubsection{\textbf{裸金属 FPGA 云服务器网络化部署与设备内存隔离}\ \ \ \textit{方向：多租户内存隔离}}{2023.06 -- 2024.06}
\begin{itemize}[parsep=0.2ex]
  \item 基于 Redfish/BMCWeb 构建节点远程管理与自动部署流程，借助 D-Bus、EEPROM 和 U-Boot 配置启动方式，并通过 TFTP/NFS 下发系统镜像，实现节点远程配置、部署和 SSD 启动。
  \item 为隔离多租户硬件逻辑对设备内存控制器的竞争，设计每租户独占的双向 DMA 路径；基于 SPDK 用户态驱动，使用大页和描述符链提交并回收 DMA 传输。
  \item 自主实现 \textbf{DMA Writer}，将驱动提供的目标地址与 MCDMA 流式数据关联，生成 AXI4-MM 写事务，实现主机侧与租户设备内存间的隔离搬运。
\end{itemize}
