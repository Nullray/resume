\section{项目经历}

\datedsubsection{
\textbf{FPGA-主机协同的PCIe外设接入系统}\ \
\textbf{\ \ \  [FPT'26第一作者论文录用]}
}{2025.04 -- 至今}

\begin{itemize}[parsep=0.2ex]

\item \textbf{需求：}面向FPGA硅前原型验证中的外设扩展与调试需求，设计远端外设接入系统，使待测处理器能够通过标准Linux PCIe软件栈使用主机侧NVMe、NIC及GPU等真实设备。

\item \textbf{虚拟PCIe Switch架构：}设计FPGA与主机软件协同的设备接入框架；FPGA vSwitch实现PCIe配置空间、BAR路由和MMIO转发，主机侧负责设备语义处理、DMA地址转换、队列管理及虚拟中断，使主机操作系统能够枚举并使用远端设备。

\item \textbf{RDMA远端接入：}扩展跨主机外设接入，将香山侧I/O请求转换为远端设备操作，并通过RDMA在两台服务器间传输数据，实现标准\texttt{nvme}/\texttt{ixgbe}等驱动下的远端外设接入。

\item \textbf{高性能数据通路：}基于PCIe P2P DMA实现本地/远端主机真实外设直接访问待测处理器内存，并面向Vortex GPU实现NVMe与GPU内存之间的GPUDirect Storage式直接数据通路。

\end{itemize}

\datedsubsection{
\textbf{SoC-FPGA可计算存储设备架构与统一编程模型}\ \
\textit{方向：近存储计算}
}{2024.07 -- 2025.06}

\begin{itemize}[parsep=0.2ex]

  \item \textbf{需求：}面向传统存储系统中数据频繁搬运带来的开销，构建可在存储设备侧加载并执行计算任务的SoC-FPGA计算存储原型。

  \item \textbf{方法：}设计统一主机编程接口，将设备内存管理、程序加载和任务执行封装为计算存储请求；完成用户缓冲区到内核请求的映射与组装，并基于QDMA、MCDMA和SPDK实现命令传输、数据搬运及设备侧异步分发。

  \item \textbf{效果：}打通主机应用到计算存储设备的端到端链路，支持主机远程管理设备内存、传输数据、加载程序和提交计算任务，并完成Blowfish、Grep和设备内存拷贝验证。

\end{itemize}

\datedsubsection{
\textbf{FPGA云服务器设备内存隔离}\ \
\textit{方向：多租户内存隔离}
}{2023.06 -- 2024.06}

\begin{itemize}[parsep=0.2ex]

  \item \textbf{需求：}解决FPGA云服务器中多个租户逻辑共享设备内存控制器时的访问竞争与相互干扰，为不同租户提供相互隔离的数据搬运通路。

  \item \textbf{方法：}为每个租户设计独立的双向MCDMA通道，并基于SPDK用户态驱动使用大页内存和描述符链提交DMA请求；实现DMA Writer，将目标地址与租户流式数据关联并转换为AXI4-MM写事务。

  \item \textbf{效果：}实现主机内存与租户设备内存之间的隔离搬运，完成多通道并行传输验证。

\end{itemize}
