\end{itemize}

\datedsubsection{\textbf{SUDA：SoC-FPGA 可计算存储设备架构与统一编程模型}}{2024.07 -- 2025.06}
\textit{可计算存储 / 异构系统软件}
\begin{itemize}[parsep=0.2ex]
  \item 参与打通主机到 SoC-FPGA CSD 的计算存储请求链路：基于 libnvme/liburing 将设备内存管理、程序加载和执行请求封装为 NVMe 风格命令，统一主机侧调用接口。
  \item 实现 nvmq/qdma 主机驱动路径，将用户缓冲区映射为内核请求，并通过 PCIe/QDMA 按命令单独传输、数据单独传输和命令携带 inline payload 三类策略下发到设备。
  \item 基于 SPDK 完善设备侧 MCDMA 轮询与命令分发：接收 QDMA 请求并按操作类型调度设备内存读写、拷贝、内存范围管理和程序执行等异步处理流程，向主机回传完成状态，实现计算存储请求的设备侧闭环。
\end{itemize}

\datedsubsection{\textbf{本科毕业设计：裸金属 FPGA 云服务器网络化部署与设备内存隔离}}{2023.06 -- 2024.06}
\textit{FPGA 裸金属云服务器 / Redfish 自动化管理 / 租户硬件逻辑访存隔离}
\begin{itemize}[parsep=0.2ex]
  \item 面向 FPGA 裸金属节点缺乏远程运维能力的问题，构建基于 Redfish/BMCWeb 的网络化管理与自动部署流程：经 D-Bus 持久化启动配置至 EEPROM，由 U-Boot 选择 SD/SSD 启动，并通过 TFTP/NFS/RAMDisk 下发文件系统，实现节点远程配置、部署和重启。
  \item 面向多租户硬件逻辑争抢设备内存控制器的问题，为每个租户设计独占的双向 DMA 数据路径；基于 SPDK/VFIO 实现用户态 MCDMA 驱动，使用大页内存维护多通道描述符链，将一次搬运的源地址、目标地址和长度下发到硬件，并完成通道启停、描述符提交与完成回收。
  \item 设计实现 \textbf{DMA Writer}：MCDMA 读取源内存后仅输出不含地址的流式数据；模块读取驱动随传输任务附带的目标地址和通道信息，将其与对应数据流关联，驱动 Data Mover 生成写入目标设备内存的 AXI4-MM 事务，完成主机侧内存与租户设备内存之间的隔离搬运。
\end{itemize}
